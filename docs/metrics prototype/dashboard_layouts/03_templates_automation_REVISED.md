## What Changed

### 1. Strategic Impact Section (NEW - Moved to Top)

**Purpose:** Show the "so what" immediately - proof that initiatives are working

**Three metric cards showing outcomes (not inputs):**
1. **Break Rate Reduction** - The risk outcome we care about
2. **Avg Confirm Time Reduction** - The efficiency outcome we care about
3. **Template Cov + Auto-Match** - Combined initiative progress

**Key Insight text:**
- One sentence connecting template/automation improvements to business outcomes
- Shows causation, not just correlation
- Example: "As template coverage increased 27pp and automation increased 18pp, break rates decreased 4.2pp..."

**Why this works:**
- Answers "is this worth it?" in first 5 seconds
- Shows outcomes (break rates) not just outputs (coverage %)
- Connects strategic initiatives to business impact

### 2. Template Coverage Section (UNCHANGED)

**Keep all existing content:**
- Coverage metric cards
- Trend chart
- By Counterparty table
- By Product Type table

**Note:** Show top 5 rows in tables with "expand for more" option

### 3. Automation Performance Section (UNCHANGED)

**Keep all existing content:**
- Auto-match rate and match score cards
- Trend chart
- By Counterparty table
- By Product Type table

**Note:** Show top 5 rows in tables with "expand for more" option

### 4. Removed Section: Combined Impact

**What was removed:**
- Grid of 4 impact cards (duplicated top cards)
- Time saved metrics (not tracking these)
- "Bottom Line" text card (narrative not needed)

**Why removed:**
- Duplicative of Strategic Impact section at top
- Time saved is hard to calculate accurately
- Text narrative feels forced/marketing-y
- Data should speak for itself

## Component Details

### Strategic Impact Section

**Metric Card 1: Break Rate Reduction**
```typescript
{
  value: number; // pp reduction (e.g., -4.2)
  timeframe: string; // "Since Apr" or "Last 6 months"
  trend: 'improving' | 'degrading';
}
```

**Calculation:**
- Compare break rate now vs. 6 months ago
- Show as negative number (reduction is good)

**Metric Card 2: Avg Confirm Time Reduction**
```typescript
{
  value: number; // days reduction (e.g., -1.3)
  timeframe: string;
  trend: 'improving' | 'degrading';
}
```

**Calculation:**
- Compare avg confirmation time now vs. 6 months ago
- Show as negative number (reduction is good)

**Metric Card 3: Combined Progress**
```typescript
{
  templateCov: number; // current % (e.g., 67%)
  autoMatch: number; // current % (e.g., 45%)
  timeframe: string;
}
```

**Display:**
- Show both numbers together: "67% + 45%"
- Emphasizes these are complementary initiatives

**Key Insight Text:**
- Auto-generated based on data
- Template: "As template coverage increased Xpp and automation increased Ypp, break rates decreased Zpp and avg confirmation time improved by N days. Strategic initiatives are working."
- Only shows if correlations are positive (don't show if things got worse!)

3. Reads: "Break rates down 4.2pp, confirmation time down 1.3 days"

## Design Considerations

**Why Move Impact to Top:**
- Executive attention span is short
- "Is this working?" should be answered immediately
- Bury the details, lead with outcomes

**Why Remove "Time Saved" Metrics:**
- Hard to calculate accurately
- Requires assumptions about manual review time
- Feels like we're justifying rather than demonstrating
- Focus on measurable business outcomes (break rates, confirmation time)

**Why Remove "Bottom Line" Text:**
- Feels marketing-y
- Data should speak for itself
- Users can form their own conclusions

**Why Keep Both Detailed Sections:**
- Users need to drill into specifics
- Counterparty/product breakdowns are actionable
- Trend charts show trajectory
- Tables allow for investigation
