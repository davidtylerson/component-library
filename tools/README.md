# Tools Directory

This directory contains various development tools and scripts used for the Float Prototype Library project.

## MCP Servers

- **playwright-mcp-server.js** - MCP server for Playwright testing automation
- **risk-metrics-mcp-server.js** - MCP server for risk metrics dashboard functionality
- **mcp-inspect.js** - Tool for inspecting MCP server functionality

## Page Inspection Tools

- **inspect-page-direct.js** - Direct page inspection utility
- **inspect-page.js** - General page inspection tool

## Usage

These tools are typically used for development, testing, and debugging purposes. They may require specific setup or dependencies to run properly.

For more information about MCP (Model Context Protocol) servers, see the project documentation.
